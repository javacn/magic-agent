# 2026-09-16

## trae 工具权限语义纠正 + 白名单降级为「默认开启所有工具」

### 起因

超哥给 `https://docs.trae.cn/cli_tool-permission`，反馈「trae 的工具启用不了」，
并要求实测「今日热点新闻」能不能返回。结论：**trae-cli 根本没有 `WebSearch` 工具**，
18 个内置工具里联网只有 `WebFetch` —— 所以「搜新闻」在 trae 上永远是模型自述，
不是工具没开。随后超哥把范围收窄为一件事：

> **「修正 allowlist 被 `-y` 架空」+「allowlist 需要默认开启所有」**

### trae-cli 权限开关的真实语义（2026-09-16 真机实测，别再凭 --help 猜）

| 开关 | 实测行为 | 证据 |
|---|---|---|
| `--allowed-tool <n>` | **只做「自动批准该工具」，不裁剪工具集** | 只传 `--allowed-tool WebFetch` → 下发的仍是全部 **18** 个工具 |
| `--disallowed-tool <n>` | **真减法**，从工具集移除 | 传 6 个补集 → 工具集 **18 → 4**（Agent / ExitPlanMode / EnterPlanMode / WebFetch） |
| `-y` / `--yolo` | 跳过全部权限检查 ⇒ 全工具可用 | 全放行路径 |
| 不传 `-y` | 工具**仍然会执行**（`-p` 非交互下） | 只传 `--allowed-tool WebFetch` 时 Bash 照样跑了 |

**18 个工具全名单**：Agent、ExitPlanMode、EnterPlanMode、Bash、BashOutput、KillShell、
Glob、Grep、LS、Read、Edit、Write、WebFetch、Skill、TaskCreate、TaskGet、TaskList、TaskUpdate。
其中前 3 个是**常驻元工具**（`--disallowed-tool` 摘不掉，做补集禁用后仍在）。
**没有 `WebSearch`**；`--allowed-tool WebSearch`（不存在的工具）**静默接受、exit 0**，
进一步印证它不是过滤器。

### 由此定下的映射（`trae.go` `buildArgs`）

```
off        逐个 --disallowed-tool 关掉实体工具（Bash/Edit/Write/Glob/Grep/Read）
on         -y（全放行）
allowlist  -y（默认开启所有工具；不再输出没有收窄能力的 --allowed-tool）
```

「白名单在 trae 上降级为全放行」是**刻意的契约**，不是实现漏做：trae 表达不了
「只允许这几个工具」，想收窄只能对补集逐个 `--disallowed-tool`，而补集随 CLI 版本
漂移（今天 18 个、明天加一个），漏一条白名单就失效，维护成本 > 收益。
与 codex 的白名单降级（`engine_base.go` 矩阵注④：白名单 → 全放行）**同构**。
→ 观感上「allowlist 被 `-y` 架空」的根源是**返回值里同时出现 `--allowed-tool` 和 `-y`**
（看起来在收窄、实际已全放行），现在直接不输出那些噪音参数。

### 顺手修掉的真 bug：off 模式漏禁 `Write`

`trae.go` off 分支此前写的是不存在的工具名 **`Replace`**（trae 的编辑/写入叫
`Edit` / `Write`），等于 **off 模式少了 Write**。抽成包变量
`traeOffDisableTools = []string{"Bash","Edit","Write","Glob","Grep","Read"}`
并注明常驻元工具摘不掉、辅助工具无外部副作用故不禁。

### 验收：nonce 闭环硬证据（4/4 绿）

随机 nonce 只出现在 URL 里，判据是 nonce 回显 + 真实工具返回（不认模型自述）：

| 用例 | 命令 | 结果 |
|---|---|---|
| E1 | `--tools on` 抓 httpbin（nonce `wf-on-24939`） | exit 0，返回 nonce ✓ |
| E2 | `--tools WebFetch` 抓 httpbin（nonce `wf-al-15564`） | exit 0，返回 nonce ✓ |
| E3 | `--tools WebFetch` **却要求用 Bash**（nonce `bash-al-32217`） | exit 0，**Bash 跑通** ✓ → 证实「默认开启所有工具」 |
| E4 | `--tools off` | 输出 `NO_TOOLS` ✓ → 证实 off 是真减法 |

`go build` OK；`go test ./...` 全绿（`internal/agent` 50.1s / `internal/cli` 1.6s）。
